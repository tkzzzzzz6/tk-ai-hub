# 蓝白科技档案站

本轮参考 [RhineLabUI](https://github.com/LBEILC/RhineLabUI) 的空间层次、资料柜构图和科技界面秩序，将网站改成以纯蓝、白色和浅蓝底色组成的资料站。主视觉使用三个立体档案盒，保留雷姆插画；资料区以易读和直接操作为主。资源内容、收藏、投稿、公开审核和账号权限沿用现有流程。

## 页面结构

- 主视觉：提示词、Skills、MCP 三个可点击档案盒，展示真实公开资源数量；点击按类型定位资源库。
- 资源库：类型、用途、标签和中英文搜索可组合；切换类型时重置不适用用途和标签。
- 卡片正面：类型、用途、摘要、标签、效果预览、收藏和中英复制入口。
- 卡片背面：中文／英文预览切换；Skills 显示 Agent 安装指令，提示词显示正文，MCP 显示使用说明。长内容只展示片段，复制仍取得对应语言的完整内容。
- 正反面右下角均为「展开详情」，直接打开完整阅读面，不触发翻转。
- 详情：来源、收藏入口、Skills 安装与 ZIP；桌面左右中英对照，手机上下排列。

## 视觉规则

- 蓝白纯色搭配，采用清晰的边框、偏硬朗的轮廓、资料编号、图标和投影表达层次。
- 不使用 CSS 线性、径向、锥形渐变或渐变蒙版。背景网格采用 SVG 线条，扫描效果采用移动的纯色线条。
- 已停止加载旧的 Liquid Glass / Living Glass 样式，避免旧的渐变背景、发光横线和材质叠加继续影响页面。
- 卡片正反面统一为白色磨砂表面、蓝色左边框和细描边；类型与用途通过文字、图标和标签区分，不再把卡片主体染成不同色板。
- 主视觉中的档案盒通过透视、硬边投影和侧边条表现立体厚度，雷姆插画作为其中一个盒面的视觉重点；周围的刻度和轨道辅助空间感。

## 动效规则

- GSAP 编排主视觉的档案盒装配入场、标签显现、分类指示器、结果卡片与复制确认反馈。
- 主视觉具有纯色扫描线、轨道刻度和轻微浮动；鼠标移动带来整组视差，悬停或键盘聚焦档案盒时，该盒子向外抽取。
- 列表容器负责入场，卡片外层负责倾斜、抬升和按压，内部翻转层负责正反面切换，避免不同动画改写同一节点的 transform。
- 点击卡片主体或标题翻到背面，再次点击主体或背面标题即可翻回；也可使用「翻回」按钮或卡片内的 Escape 返回正面。翻转过渡可被新的状态打断。
- 输入搜索文本不反复播放整个列表；分类、用途或分页改变结果时采用横向的档案排入场。
- 触屏不使用悬停倾斜。系统减少动态效果优先于网站开关。
- 关闭动效或系统减少动态效果时，取消入场、倾斜、按压与环境循环动画，正反面立即切换；静态资料盒与搜索、复制、收藏、分类和详情操作仍可使用。
- 主视觉离开视口时暂停环境循环；标签页隐藏时暂停动画并清理指针状态；组件卸载时清理监听、观察器与动画。
- GSAP 媒体上下文的事件函数在同一上下文中注册，避免父子上下文循环引用。

## 交互细节

- 复制、收藏、语言选择、标签、来源链接和效果预览控件独立响应，不会误触卡片翻转。选中文本不会翻转；正文支持滚动阅读。
- 卡片隐藏的一面同时设置 `inert` 与 `aria-hidden`，其中的控件不参与 Tab 顺序或辅助阅读。键盘启动翻转后，焦点移到背面的「翻回」；返回正面后恢复到标题按钮。
- 打开详情后保留卡片当前正反面，关闭详情时恢复到打开它的按钮。
- `/` 或 `Ctrl/Cmd K` 聚焦搜索；编辑表单和弹窗内不会截获 `/`。
- 收藏请求按资料 ID 加锁，保存中显示等待状态，避免连续点击产生并发写入。
- 缺失语言版本的复制请求会提示补齐内容；不会写入空文本。预览截断不影响完整复制。
- 空收藏提供返回资源库入口；全部筛选可单独移除或一起清除。

## 验证方法

```text
node scripts/check-library.mjs
node node_modules/typescript/bin/tsc --noEmit --incremental false
node scripts/run-framework.mjs build
```

还需检查桌面与手机布局、快速分类切换、英文搜索、连续正反切换、双语预览、鼠标倾斜与按压、隐藏面的键盘隔离、Escape 翻回、动效开关、复制、收藏、ZIP 入口和详情关闭焦点。浏览器验收结果应以实际执行为准，静态审查不等同于浏览器验证。
