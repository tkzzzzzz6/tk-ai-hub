# 冰蓝档案舱

这次改版把游戏界面的空间感放在雷姆主视觉和操作反馈上，资料卡片使用中性的半透明毛玻璃表面、柔和阴影和 3D 翻转。分类颜色集中在纯色左侧边框，资料区保持清晰的蓝白阅读面。资源继续使用原来的公开、收藏、投稿和审核流程，未修改数据库内容或权限。

## 页面结构

- 主视觉：真实的提示词、Skills、MCP 数量；类型入口直接定位资源库。
- 资源库：类型、用途、标签和中英文搜索可组合；切换类型时重置不适用用途和标签。
- 卡片正面：类型、用途、摘要、标签、效果预览、收藏和中英复制入口。
- 卡片背面：中文／英文预览切换；Skills 显示安装指令，提示词显示正文预览。长内容只展示片段，复制仍取得对应语言的完整内容；通过「展开详情」进入完整阅读面。
- 详情：来源、收藏入口、Skills 安装与 ZIP，桌面左右中英对照，手机上下排列。

## 卡片视觉

- 卡片正反面统一使用半透明白色毛玻璃、背景模糊、细描边与柔和投影；正文和标签保持中性颜色。
- 分类识别统一放在 4px 纯色左侧边框，移除顶部的渐变横线与额外横向装饰。不同用途沿用色板：生图粉色、视频橙色、科研与设计紫色、学习与文档绿色、编程蓝色、写作与翻译黄色，其他用途灰蓝。
- Skills 使用蓝色左边框，MCP 使用青绿色左边框。类型图标与分类名称同时保留，颜色不是唯一识别方式。
- 用途筛选仍用对应色板；详情标题区采用中性底色与纯色左边框，不再把整张卡片染成分类颜色。

## 动效规则

- GSAP 编排一次主视觉入场、分类指示器、结果卡片和复制确认反馈。
- 列表的资源容器负责入场，卡片外层负责鼠标倾斜、抬升和按压，内部翻转层负责正反面切换，避免不同动画改写同一节点的 transform。
- 精细指针在卡片内移动时产生明显的 3D 倾斜、轻微抬升与跟随高光；按下时卡片缩小、回落，释放后弹性恢复。复用可打断的 GSAP 动画，快速移动或按压会朝最新状态过渡。
- 点击卡片空白处、标题或「翻转查看」后，卡片绕 Y 轴翻到背面；「翻回」或卡片内的 Escape 返回正面。快速改变翻转状态可以打断过渡。
- 输入搜索文本不反复播放整个列表；快速切换可以打断上一段动画。
- 触屏不使用悬停倾斜。系统减少动态效果优先于网站开关。
- 网站开关记在浏览器本地；关闭动效或系统减少动态效果时，取消倾斜、按压、环境动画和翻转过渡，正反面立即切换，搜索、复制、收藏与详情入口仍可用。
- 主视觉离开视口后暂停环境动画，标签页隐藏时暂停动画，组件卸载时清理。
- GSAP 媒体上下文的事件函数在同一上下文中注册，避免父子上下文循环引用。

## 交互细节

- 复制、收藏、标签、来源链接和效果预览控件独立响应，不会误触卡片翻转。视频创作独立于前端动效。
- 卡片隐藏的一面同时设置 `inert` 与 `aria-hidden`，其中的控件不参与 Tab 顺序或辅助阅读。键盘启动翻转后，焦点移到背面的「翻回」；返回正面后恢复到标题按钮。
- `/` 或 `Ctrl/Cmd K` 聚焦搜索；编辑表单和弹窗内不会截获 `/`。
- 收藏请求按资料 ID 加锁，保存中显示等待状态，避免连续点击产生并发写入。
- 关闭详情后恢复到打开它的按钮；按钮焦点和筛选选中状态对键盘与辅助阅读可见。
- 空收藏有返回资源库入口；全部筛选可单独移除或一起清除。

```text
node scripts/check-library.mjs
node node_modules/typescript/bin/tsc --noEmit
node scripts/run-framework.mjs build
```

浏览器检查还包括桌面与手机布局、快速分类切换、英文搜索、卡片翻转及双语预览、鼠标倾斜与按压、隐藏面的键盘隔离、Escape 翻回、动效开关、收藏、复制、ZIP 入口、详情关闭焦点和投稿入口。
