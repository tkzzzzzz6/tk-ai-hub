# 冰蓝档案舱

这次改版把游戏界面的空间感放在雷姆主视觉和操作反馈上，资料区保持清晰的蓝白阅读面。资源继续使用原来的公开、收藏、投稿和审核流程，未修改数据库内容或权限。

## 页面结构

- 主视觉：真实的提示词、Skills、MCP 数量；类型入口直接定位资源库。
- 资源库：类型、用途、标签和中英文搜索可组合；切换类型时重置不适用用途和标签。
- 卡片：中英复制、Skills 安装指令、效果预览、详情与收藏。
- 详情：来源、收藏入口、Skills 安装与 ZIP，桌面左右中英对照，手机上下排列。

## 动效规则

- GSAP 编排一次主视觉入场、分类指示器、结果卡片和复制确认反馈。
- 卡片外层负责入场，内层负责鼠标倾斜，避免同时改写同一节点的 transform。
- 输入搜索文本不反复播放整个列表；快速切换可以打断上一段动画。
- 触屏不使用悬停倾斜。系统减少动态效果优先于网站开关。
- 网站开关记在浏览器本地；关闭后不影响搜索、复制和收藏。
- 主视觉离开视口后暂停环境动画，标签页隐藏时暂停动画，组件卸载时清理。
- GSAP 媒体上下文的事件函数在同一上下文中注册，避免父子上下文循环引用。

## 交互细节

- 提示词按审核后的用途自动配色：生图浅粉、视频浅橙、科研与设计浅紫、学习与文档浅绿、编程浅蓝、写作与翻译浅黄，其他用途灰蓝。Skills 与 MCP 保留原有蓝色。
- 用途按钮、提示词卡片、标签和详情标题区使用同一套色板；正文与标题保持清晰文字，保留分类名称与图标，不单靠颜色辨认。视频创作独立于前端动效。

- `/` 或 `Ctrl/Cmd K` 聚焦搜索；编辑表单和弹窗内不会截获 `/`。
- 收藏请求按资料 ID 加锁，保存中显示等待状态，避免连续点击产生并发写入。
- 关闭详情后恢复到打开它的按钮；按钮焦点和筛选选中状态对键盘与辅助阅读可见。
- 空收藏有返回资源库入口；全部筛选可单独移除或一起清除。

## 验证

```text
node scripts/check-library.mjs
node node_modules/typescript/bin/tsc --noEmit
node scripts/run-framework.mjs build
```

浏览器检查还包括桌面与手机布局、快速分类切换、英文搜索、动效开关、收藏、复制、ZIP 入口、详情关闭焦点和投稿入口。

参考：UI UX Pro Max 的 HUD / Sci-Fi FUI、焦点与动态效果指导，GSAP 官方 React / Timeline / Performance Skills，以及 Anthropic Frontend Design 的视觉构图、界面文案与交互反馈原则。蓝白配色、系统无衬线字体、中英对照和管理员审核沿用项目约定。
